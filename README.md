# 🧠 Memory Management — Personal AI Agent

A voice-first, full-stack personal AI assistant and memory management system supporting Hindi, English, and Hinglish. Runs with intelligent persistent memory extraction, multi-session context continuity, daily task journaling, autonomous browser search & navigation, and a clean, modern UI inspired by ChatGPT's light theme.

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite + Tailwind CSS |
| UI Design | ChatGPT-inspired Light Theme (with Night mode support) |
| Backend | Node.js + Express |
| Database | MongoDB Atlas + Mongoose |
| AI Engines | Configurable LLM (OpenAI / Gemini / Local Rule Engine) |
| Voice | Continuous Web Speech Recognition + Text-to-Speech (TTS) |
| Automation | Autonomous Web Search & Navigation + Chrome Extension (Manifest V3) |
| Auth & Security | JWT (Access + Refresh tokens) + Google OAuth (GIS) + Secret Sanitizer |

---

## 🌟 Key Features

- **🧠 Intelligent Personal Memory:**
  - Automatic background extraction of long-term preferences, decisions, and goals from chats.
  - Smart deduplication & merging to prevent duplicate entries.
  - Multi-session conversation recall and context grounding.
  - Category indexing (`personal`, `preference`, `goal`, `project`, `decision`, `fact`, `contact`).
  - Strict secret sanitization redacting passwords, API keys, and connection strings.

- **💬 ChatGPT-Inspired Clean UI:**
  - Pure white conversation canvas (`#FFFFFF`) with centered welcome hero (*"What's on your mind today?"*).
  - Off-white sidebar (`#F7F7F8`) with subtle borders (`#E5E7EB`) and "+ New Chat" button.
  - Teal avatar badge (`#0F766E`) with white initials.
  - Modern rounded chat input bar with a distinct blue voice input button (`#2563EB`).
  - Seamless toggle between daytime White Mode and eye-friendly Night Mode.

- **🎙️ Continuous Multi-Lingual Voice:**
  - Hands-free continuous listening in Hindi (हिंदी), English, and Hinglish.
  - Automatic voice boundary detection (pause speech to send).
  - Echo-free TTS audio readout with automatic microphone pause/resume.

- **🌐 Autonomous Web & Browser Assistant:**
  - Natural language intent parser for web searches, documentation lookups, and official websites.
  - Multi-step execution planning with verification badges.
  - One-click browser launching and AI webpage summarization.
  - Chrome Extension (Manifest V3) integration for active tab scraping and autofill.

- **📋 Productivity & Journal:**
  - Daily tasks with priority badges, status filters, and category tagging.
  - Automated daily work summaries generated by AI.
  - Research library for bookmarking and summarizing documentation & articles.

## ⚡ Quick Start

### Prerequisites
- Node.js 20+
- MongoDB Atlas account (or local MongoDB)
- npm 10+

### 1. Clone & Install

```bash
git clone https://github.com/bm100695-cpu/memory-management-.git
cd memory-management-

# Install backend dependencies
cd backend && npm install

# Install frontend dependencies
cd ../frontend && npm install
```

### 2. Configure Environment

```bash
cp .env.example backend/.env
# Update backend/.env with your MongoDB URI, JWT secrets, and AI API keys
```

### 3. Run Development Servers

```bash
# Terminal 1 — Backend API
cd backend && npm run dev

# Terminal 2 — Frontend Application
cd frontend && npm run dev
```

- **Frontend:** http://localhost:5173  
- **Backend API:** http://localhost:5000

## 🔒 Security & Privacy

- Never commit `.env` files.
- Sensitive credentials (passwords, API keys, MongoDB URIs) are sanitized before memory persistence.
- JWT tokens use httpOnly cookies for refresh.
- Rate limiting and input validation applied across all API endpoints.
- User memory and task data is strictly isolated by authenticated user ID.
